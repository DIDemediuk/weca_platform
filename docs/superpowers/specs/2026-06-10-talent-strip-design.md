# Дизайн: смужка «олівці талантів» у верхній частині PDF звіту

**Дата:** 2026-06-10
**Статус:** затверджено користувачем (brainstorming через візуальні макети)

## Мета

Замінити градієнтну смугу у верхній частині кожної сторінки PDF звіту на
персоналізовану смужку з сегментів — щоб звіт виглядав професійно, тепло
і не банально. Батьки мають бачити, що звіт зроблено індивідуально для
їхньої дитини.

## Відхилені альтернативи

- Товста смуга з заголовком «ТАЛАНТИ» — займає місце, менш витончено.
- Хвиляста стрічка з градієнтом — жива форма, але залишається градієнт.
- Гірлянда прапорців — святково, але занадто «дитячо» для балансу
  професіоналізм/теплота.
- Декоративні фіксовані сегменти — однакові в усіх звітах, нема
  персоналізації.

## Затверджене рішення

**8 заокруглених сегментів** («олівці») в один ряд, по одному на кожен
інтелект за методикою Гарднера, в порядку `INTELLIGENCE_TYPES`
(src/domain/types.ts).

### Довжини (flex-частки)

- Головний талант (`primaryType`) — **3x**
- Другий талант (`secondaryType`) — **2x**
- Решта шість — **1x**
- Якщо `secondaryType` відсутній — один сегмент 3x, решта сім по 1x
  (узгоджено з логікою радар-діаграми: highlighted = 1.0, базовий = 0.45)

Числових балів у системі немає — персоналізація йде від
`primaryType`/`secondaryType`, тих самих даних, що живлять радар.
Кожна комбінація талантів дає унікальний візерунок смужки.

### Кольори

Кожному з 8 типів — фіксований колір з фірмової палітри `C`
(navy, orange, yellow, green, sky — циклічно), підібраний так, щоб сусідні
сегменти не повторювались. Чисті кольори без градієнта.

### Геометрія

- Висота сегментів: ≈2.5мм
- Проміжок між сегментами: ≈2мм
- `border-radius: 999px`
- Розташування: у межах полів сторінки (відступ 12.5мм з боків),
  над хедером кожної з 3 сторінок

## Технічна реалізація

Усе в `src/services/reportTemplate.ts`:

1. **Видалити** `.page::before` (градієнтна смуга) і `.page::after`
   (тіньова лінія під нею) — сегменти самодостатні.
2. **Додати** функцію `talentStrip(primaryType, secondaryType)`, що
   генерує `<div class="talent-strip">` з 8 `<span>`; flex-частка та
   колір кожного визначаються типом.
3. **Вставити** виклик `talentStrip(...)` на початку кожної з 3 секцій
   `.page` (перед `<header class="header">`).
4. CSS для `.talent-strip` (flex, gap) і сегментів.

Шаблон уже отримує `report.primaryType` і `report.secondaryType` через
`TemplateArgs.report` — нові дані не потрібні.

## Перевірка

- Згенерувати preview PDF (`npm run pdf:preview`) для дитини
  з обома талантами та для дитини лише з головним талантом.
- Переконатися, що смужка в межах полів, сегменти не злипаються
  і не переносяться на другий рядок.
- Існуючі тести (`npm test`) проходять.
