# Конструктор звітів за теорією Гарднера — WestCamp Kids

**Дата:** 2026-06-08
**Статус:** Затверджено до планування

## Мета

Веб-застосунок, що дозволяє тім-лідерам дитячого табору за хвилину згенерувати
персональний PDF-звіт про дитину на основі теорії множинного інтелекту Гарднера.
Звіт виглядає як ексклюзивний дизайнерський продукт у брендстилі WestCamp Kids,
створює «вау-ефект» у батьків і служить безкоштовним цінним бонусом до путівки.

Ключова відмінність від «конвеєрної брошури»: у PDF потрапляють **тільки** обрані
1-2 типи інтелекту конкретної дитини, з живим прикладом від тім-лідера, вплетеним
у текст за допомогою ШІ.

## Користувачі та доступ

- **Тім-лідер** — заповнює форму з телефона. Доступ за секретним посиланням
  `/f/<секрет>`, без логіна (на старті).
- **Координатор (адмін)** — керує змінами й контентом, бачить історію звітів.
  Доступ за окремим секретним посиланням `/admin/<секрет>`.
- Архітектуру закласти так, щоб повноцінні логіни/ролі додавались пізніше без
  переробки (на перспективу).

## Стек

- **Бекенд:** Node.js + TypeScript, фреймворк Fastify.
- **БД:** SQLite (файл на диску-волюмі). Перехід на Postgres має бути безболісним
  (шар доступу до даних ізольований).
- **Фронт:** серверний рендер HTML, мобільний-перший, мінімум JS, без важких
  фреймворків.
- **ШІ:** DeepSeek API (OpenAI-сумісний ендпойнт, модель `deepseek-chat`).
- **PDF:** генерація через headless-браузер Playwright (HTML+CSS → PDF).
- **Хостинг:** Railway, Docker-образ із вшитим Playwright.

### Ключове рішення — генерація PDF

PDF будується як HTML+CSS-сторінка у брендових кольорах, яку Playwright рендерить
у PDF. Це дає піксель-в-піксель дизайнерський вигляд (шрифти, фото, діаграма,
заокруглення) і правиться як звичайна веб-сторінка.

Відкинуті альтернативи: бібліотеки на кшталт pdfkit (малювання координатами —
непридатне для гарного дизайну) та no-code-збірки (саме від них ми відходимо).

## Брендстиль (з kids.westcamp.in.ua)

- Палітра: лісова зелень + теплі дерев'яні тони; бірюзовий/teal як акцент;
  м'які нейтральні (білий, світло-сірий) для фону.
- Типографіка: чистий сучасний sans-serif; жирні впевнені заголовки, легкий
  читабельний основний текст.
- Тон: «безпечна пригода», тепло, автентичні фото дітей.
- Слоган-орієнтир: «Перша безпечна подорож у самостійність».

## Складові (модулі)

1. **Форма тім-лідера** (`/f/<секрет>`)
   Поля: ПІБ дитини; № зміни; тип інтелекту 1 (обов'язковий); тип 2
   (необов'язковий); живий приклад (текст, 1-3 речення); фото дитини.
   Мобільний-перший, великі поля, валідація на льоту.

2. **Адмінка** (`/admin/<секрет>`)
   Список згенерованих звітів; керування змінами; перегляд та повторне
   завантаження PDF; редагування базових описів 8 типів інтелекту.

3. **Контент-движок**
   8 базових описів типів інтелекту зберігаються в БД, редагуються в адмінці.
   Чернетки 8 описів пише виконавець (українською, теплий таборовий тон):
   сильні сторони, як проявляється в таборі, поради батькам.

4. **ШІ-вставка (DeepSeek)**
   Бере сухий приклад тім-лідера → повертає 1-2 теплі персональні абзаци,
   вплетені у звіт. Запасний варіант, якщо API недоступний: приклад вставляється
   як охайна цитата, PDF усе одно генерується.

5. **Рендерер PDF (Playwright)**
   HTML-шаблон звіту → PDF. Структура звіту:
   - Обкладинка: фото дитини, ім'я, № зміни, брендинг.
   - Радарна діаграма всіх 8 типів; обрані 1-2 підсвічені бірюзовим, решта
     приглушені.
   - Описи **тільки** обраних 1-2 типів.
   - Живий коментар тім-лідера (вплетений ШІ).
   - Сторінка «Як підтримати ці сильні сторони вдома» (поради батькам по обраних
     типах).

6. **Сховище**
   Запис у БД (дитина, зміна, обрані типи, приклад, шлях до фото, час створення)
   + файл фото на диску-волюмі.

## Потік даних

Форма → валідація → запис у БД → ШІ-вставка (DeepSeek, з фолбеком) → збірка HTML
зі шаблону → Playwright рендерить PDF → файл віддається на завантаження і лишається
в історії адмінки.

## Діаграма

Радарна («павутинка») на 8 осей, рендериться як вбудований SVG у HTML (без
зовнішніх залежностей). Обрані типи підсвічені бірюзовим, решта приглушені.

## Доставка

Тім-лідер тисне «Згенерувати» → одразу завантажує PDF на телефон → сам пересилає
батькам в особисті (Viber/Telegram). На старті — лише завантаження файлу (постійні
посилання на звіт можна додати пізніше).

## Обробка помилок

- Порожні обов'язкові поля / немає фото → зрозуміле повідомлення у формі.
- ШІ недоступний → запасний текст (цитата), PDF генерується.
- Збій рендера PDF → повтор; помилка фіксується й видима в адмінці.

## Тестування

- **Юніт:** валідація форми; ШІ-вставка (з мок-відповіддю); логіка вибору сторінок
  за обраними типами; генерація SVG-діаграми з підсвіткою правильних осей.
- **Інтеграційний:** повний прогін «форма → PDF-файл існує і не порожній».
- **Візуальний чек:** згенерувати приклад PDF на тестових даних і оком звірити
  з брендстилем.

## 8 типів інтелекту за Гарднером (для контенту)

1. Лінгвістичний (вербальний)
2. Логіко-математичний
3. Просторовий (візуальний)
4. Тілесно-кінестетичний
5. Музичний
6. Міжособистісний (комунікативний)
7. Внутрішньоособистісний (рефлексивний)
8. Натуралістичний

## Поза межами цього етапу (YAGNI)

- Повноцінні логіни/ролі та реєстрація користувачів.
- Постійні веб-посилання на звіти й перегляд звіту як веб-сторінки.
- Повна ШІ-генерація всього тексту звіту з нуля.
- Postgres (закладаємо лише можливість переходу).
- Аналітика переглядів, нотифікації, інтеграції з месенджерами.
